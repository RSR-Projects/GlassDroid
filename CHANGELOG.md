# Changelog

All notable changes for **GlassDroid Basic** (`com.rsrprojects.glassdroid`) by **RSR Projects** will be documented in this file.

## [Unreleased]

Version `2.0.4` (`versionCode` `2000054`), forked from **F-Droid Basic** (`2.0.3`) with custom F-Droid Liquid Glass icon and RSR Projects branding.

### Added & Customised
- **Optical Liquid Glass UI:** Integrated Kyant0 `backdrop` (`2.0.1`) and `capsule` (`2.1.3`) across floating top bars, cards, switches, sliders, dialogs, menus, toasts, and overlays.
- **Hold-and-Swipe Bottom Dock:** Dual-backdrop floating navigation capsule with draggable jelly droplet refraction over `Discover`, `Search`, and `My Apps`, plus hold-to-open Search and adaptive tablet `NavigationRail`.
- **Fluid Motion & Transitions:** Elastic squish physics (`liquidSquish`), touch ripples, staggered card entrances, icon pop animations, scroll parallax depth, shimmer sweeps, and refractive app-opening portal transitions.
- **Glass & Motion Customizer:** Added `Adaptive`, `Clear`, `Frosted`, `Deep`, and `Custom` glass presets, tint swatches, transparency, highlight intensity, Reduced Visual Effects mode, global animation toggle, animation intensity, motion profiles, and per-tab reset actions.
- **RSR Projects Identity & About Screen:** Configured package ID `com.rsrprojects.glassdroid`, app name `GlassDroid Basic`, official RSR Projects / GitHub / upstream F-Droid links, open-source acknowledgements, and repository star action.

# Security Policy

## Reporting a Vulnerability

If you discover a security issue in **GlassDroid Basic** (`com.rsrprojects.glassdroid`):

1. **Do not** disclose sensitive exploit details in a public GitHub issue before a fix is available.
2. Report the vulnerability privately through **[GitHub Security Advisories](https://github.com/RSR-Projects/GlassDroid/security/advisories)** on the project repository (`https://github.com/RSR-Projects/GlassDroid`).
3. Include the affected component, GlassDroid Basic version, Android version, and clear reproduction steps.

For vulnerabilities originating in upstream F-Droid repository verification, indexing, or download libraries (`libs/`), please also review or report via upstream **[F-Droid Client security guidance](https://gitlab.com/fdroid/fdroidclient)**.
